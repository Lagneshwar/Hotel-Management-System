### Hotel Management OOP Project

A Java-based **console application** designed to manage basic hotel operations.

### Main Features

* Manage and store guest information
* Book different types of hotel rooms
* Check room availability and features
* Order food for booked rooms
* Checkout guests and generate bills
* Save hotel details to a file
* Restore saved data when the application starts
* Perform file saving using a separate thread
* Handle invalid operations and exceptions
* Prevent booking of already occupied rooms using a custom exception

###  Concepts Used
Classes & Objects, Inheritance, ArrayList, Interfaces, File Handling, Object Serialization, Exception Handling, Custom Exceptions, Multithreading
